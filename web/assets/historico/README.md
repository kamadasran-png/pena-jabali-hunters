# HISTÓRICO — Recursos documentales

Espacio reservado para recursos históricos recuperados y aprobados para la nueva web.

## Flujo documental

WEB ANTIGUA DEL 50.º ANIVERSARIO
→ fuente documental
→ documentación recuperada
→ identificación ANT-XX
→ análisis
→ derivado aprobado
→ publicación web

La antigua web no se reconstruye automáticamente. Los materiales históricos se seleccionan y tratan individualmente.

El artículo de Fernando García mantiene su identidad editorial y autoría y no se convierte automáticamente en un registro ANT-XX.
