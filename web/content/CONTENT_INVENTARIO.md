# C.13 — INVENTARIO MAESTRO DE CONTENIDOS

## Alcance

Inventario de contenidos del proyecto WEB Y APP PEÑA JABALÍ HUNTERS.

### Fuentes admitidas
- Web antigua creada con motivo del 50.º aniversario.
- Archivo histórico de la Peña.
- Documentación propia de la Peña.
- Material actual generado para este proyecto.
- Nueva documentación que se incorpore posteriormente al proyecto.

### Exclusión expresa
El material de **Nicoleta** queda fuera del alcance de este inventario. No debe buscarse, indexarse, clasificar­se, mezclarse ni incorporarse al contenido de Peña Jabalí Hunters mediante este inventario.

## Clasificación

- **A — Publicable:** aprobado y listo para publicación.
- **B — Revisar:** material válido pendiente de revisión.
- **C — Pendiente:** contenido que debe incorporarse pero aún no está disponible.
- **D — Histórico:** material procedente del archivo histórico.
- **E — Descartado:** material que no se utilizará.

## Ficha mínima

Cada elemento deberá registrar, cuando proceda:

- ID
- Tipo
- Nombre
- Fuente
- Página destino
- Categoría
- Estado
- Autor / procedencia
- Fecha
- Observaciones

## Regla de publicación

ENCONTRADO → IDENTIFICADO → CLASIFICADO → REVISADO → APROBADO → PUBLICADO

No se publicará automáticamente un material por el mero hecho de haber sido localizado.

## Histórico

La documentación histórica seguirá el sistema ANT-XX cuando corresponda.

La web del 50.º aniversario se considera fuente documental y no se importará automáticamente a la nueva web.

El artículo de Fernando García conservará su autoría, contexto e identidad editorial y se gestionará como contenido histórico específico.

## No duplicación

Un dato oficial deberá tener una única fuente de verdad. Las páginas y componentes deberán consumir ese contenido o dato en lugar de mantener copias manuales independientes.

## Prioridad inicial

1. Contenido institucional y de historia.
2. Caza.
3. Cotos.
4. Tarjetas y jornadas.
5. Galería y material histórico adicional.
6. Contenido comercial avanzado.

## Estado C.13

Definición aprobada e inventario maestro preparado. El contenido real se incorporará en las fases correspondientes.
