# DATA — Datos estructurados

Esta carpeta queda reservada para los datos estructurados que alimentarán los componentes de la web.

## Entidades previstas

- Cotos
- Especies
- Modalidades
- Tarjetas
- Jornadas
- Ofertas

## Principio de fuente única

Un dato oficial debe tener una única fuente de verdad. Las páginas y componentes deberán presentar los datos desde esta capa, evitando duplicaciones manuales.

## Estados

BORRADOR → EN REVISIÓN → APROBADO → PUBLICADO

Los datos reales se incorporarán únicamente en su fase correspondiente.
